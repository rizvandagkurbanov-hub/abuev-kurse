# Abuev — конвертер валют и криптовалют

Мобильное веб-приложение (PWA) для быстрого пересчёта валют и криптовалют по курсам к рублю.
Работает офлайн, устанавливается на телефон, поддерживает 10 языков и светлую/тёмную тему.

**Сайт:** https://rizvandagkurbanov-hub.github.io/abuev-kurse/

## Возможности

- **46 валют**: 26 обычных + 20 криптовалют.
- **Живые курсы** к рублю из бесплатного [Exchange Rate API](https://github.com/fawazahmed0/exchange-api) (обновление раз в день, без ключей и лимитов).
- **Настоящий график** изменения курса за 7 и 30 дней (исторические данные того же API).
- **Конвертер**: сумма, выбор базовой валюты, поиск, избранное (★), копирование и «поделиться».
- **Экран «Курсы»**: весь список с возможностью править значения вручную (например, курс банка).
- **10 языков**: русский, английский, испанский, немецкий, французский, китайский, японский, португальский, хинди, арабский (с RTL).
- **Темы**: светлая, тёмная и «как в системе».
- **PWA**: манифест, иконки, service worker, установка на главный экран, офлайн-режим.
- **Доступность**: aria-атрибуты, управление с клавиатуры, `prefers-reduced-motion`.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | разметка приложения, мета-теги, OG-превью |
| `style.css` | все стили, светлая/тёмная тема, адаптивность |
| `lang.js` | переводы интерфейса (10 языков) |
| `data.js` | списки валют и резервные курсы |
| `update.js` | форматирование чисел и дат, буфер обмена, тосты |
| `animations.js` | раскрытие вкладок, сортировка избранного, счётчик, «пилюля» меню |
| `app.js` | состояние, рендер, загрузка курсов, график |
| `sw.js` | service worker (офлайн-кэш) |
| `manifest.json` | манифест PWA |
| `icons/` | иконки 192/512, maskable, apple-touch, favicon |

## Как запустить локально

Нужен любой статический сервер (не открывайте `index.html` двойным кликом — service worker не заработает):

```bash
python -m http.server 8000
# затем откройте http://localhost:8000
```

## Как обновлять

1. Меняете файлы.
2. **Обязательно** увеличиваете `VERSION` в `sw.js` (`abuev-v1` → `abuev-v2`), иначе у пользователей останется старая версия из кэша.
3. Коммитите в `main` — GitHub Pages обновится через 1–2 минуты.
